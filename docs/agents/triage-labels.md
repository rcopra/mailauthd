# Triage Labels

The five canonical triage roles, with label strings equal to their names:

| Role | Label | Meaning |
|---|---|---|
| Needs triage | `needs-triage` | New/unsorted; not yet assessed |
| Needs info | `needs-info` | Blocked on missing details before work can start |
| Ready for agent | `ready-for-agent` | Fully specified; an agent can pick it up and complete it |
| Ready for human | `ready-for-human` | Specified, but requires a human (e.g. judgment, credentials, external steps) |
| Won't fix | `wontfix` | Deliberately not done |

Default vocabulary kept as-is (chosen during setup). Apply exactly these
strings when labeling issues.
